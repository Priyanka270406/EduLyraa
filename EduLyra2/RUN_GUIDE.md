# EduLyra — Run Guide

1. Open PowerShell in this folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the Local URL shown by Vite (normally `http://localhost:5173/`).

For another device on the same Wi-Fi/network, run:

`npm run dev -- --host 0.0.0.0`

Then open the Network URL shown by Vite, for example `http://YOUR-PC-IP:5173/`.
